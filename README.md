# SPRANG Kasse – Updates

Dieses Repository enthält **nur die veröffentlichten Installer** der SPRANG Kasse (unter *Releases*).
Die Kassen holen sich hier automatisch neue Versionen.

- Stabile Versionen: normale Releases (`latest.yml`)
- Pilot-Versionen: Vorab-Releases `x.y.z-beta.n` (`beta.yml`)

Der Quellcode liegt nicht hier. Die Installer enthalten keine Zugangsdaten.
